# FAQ & Troubleshooting

If you have any problems, take a look here first and try to find it. If you don't, report an issue [in the Nuit Github Issues](https://github.com/Nuit-Bot/Nuit/issues).

## `TokenInvalid`

This means your token isn't correct (doesn't exist) or you simply didn't give one.
